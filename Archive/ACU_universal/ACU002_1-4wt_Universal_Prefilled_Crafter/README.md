Universal crafter that can be set up to accept any recipe with up to 4 items and tiled net to each other.
## Features
- Accepts any recipe
- Can accept up to 4 items
- Tiled layout
- Runout protection
- Stops crafting when output chest is full
## Considerations
- Uses item frame
- Output cannot be accessed by a hopper
- On crafts that produce more than 1 item, items can be spitted out on last craft
