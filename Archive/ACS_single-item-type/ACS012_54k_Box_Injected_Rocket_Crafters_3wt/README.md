Rocket crafters that craft at 2x Hs directly into a shulker box. SS14 detection initiates a countdown to break the box as soon as it fills completely, outputting full boxes. Rate: 30box/h.
## Features
- Clocked at 4gt, crafts 54k rockets/h
- Crafts directly into shulker box
- Low Inv. shut-off
- Box Accessible
- Toggless
- Tile-able
## Considerations
- Does not craft paper from cane, requires paper at input
## Instructions
1. All crafter inventories have to be prefilled with 1 stack of items for each slot
2. Place first empty box at output, pre-fill dispenser and dropper in box loader with 1 empty shulker each
## Notes
The crafters can be tiled indefinitely but should be grouped and sequentially tiled, (eg. D111,D222,D333)
## Compatibility
Tested in 1.21.11
